# Roadmap

[简体中文](ROADMAP.zh-CN.md) | English

The project is built incrementally, from a working core outward.

| Milestone | Focus | Deliverable |
|---|---|---|
| M0 | Foundation | Repo skeleton, spec, conventions |
| M1 | Core loop | Strategy chain + execution chain (Resolve → Intent → Dispatch → Collect) |
| M2 | Lifecycle | Inbox-driven state machine, streaming, abort, step cap |
| M3 | Traceability & plugins | Event-sourced sessions, replay; SPI / Node bridge / MCP plugins |
| M4 | Product | React chat UI, CLI, docs, CI, release |
