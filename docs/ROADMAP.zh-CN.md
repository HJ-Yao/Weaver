# 路线图

English | [简体中文](ROADMAP.zh-CN.md)

项目以“先跑通核心，再向外扩展”的方式逐步构建。

| 里程碑 | 重点 | 产出 |
|---|---|---|
| M0 | 地基 | 仓库骨架、规格、规范 |
| M1 | 核心循环 | 策略链 + 执行链（Resolve → Intent → Dispatch → Collect） |
| M2 | 生命周期 | inbox 驱动状态机、流式输出、中止、步数上限 |
| M3 | 溯源与插件 | 事件溯源会话、回放；SPI / Node 桥接 / MCP 插件 |
| M4 | 产品化 | React 聊天界面、CLI、文档、CI、发版 |
